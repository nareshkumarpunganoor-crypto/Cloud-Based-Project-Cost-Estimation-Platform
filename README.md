# ☁️ Cloud-Based Project Cost Estimation Platform

A **Cloud-Based Project Cost Estimation Platform** designed to help users quickly estimate project costs based on resources, requirements, and project parameters. The platform provides a simple and user-friendly interface for calculating estimated expenses and supporting better project planning and budgeting.

## 🚀 Live Demo

### 🌐 CloudCost Pro – Project Cost Estimation Platform

👉 **Live Application:**
https://cloud-based-project-cost-estimation.onrender.com/

## 📌 Project Overview

**CloudCost Pro** is a cloud-based web application that simplifies project cost estimation. Instead of manually calculating different project expenses, users can enter relevant project details and receive an estimated project cost.

The application is designed as a **Cloud Computing project** and demonstrates how a web-based cost estimation system can be deployed and accessed through the cloud.

## 🔄 How It Works

1. Open the **CloudCost Pro** web application.
2. Enter the required project information.
3. Provide the required resources or project parameters.
4. The Flask backend processes the submitted information.
5. The cost estimation logic calculates the estimated project cost.
6. The estimated result is displayed to the user.
7. Users can use the estimation for project planning and budgeting.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/nareshkumarpunganoor-crypto/Cloud-Based-Project-Cost-Estimation-Platform.git
```

### 2. Navigate to the Project

```bash
cd Cloud-Based-Project-Cost-Estimation-Platform
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
